1 Values🔗ℹ

1.1 Money🔗ℹ

procedure

(money currency minor-units) → money?

  currency : string?
  minor-units : exact-nonnegative-integer?
Represents money exactly in the currency’s smallest configured unit. Currency is an uppercase three-letter ISO 4217 code. Floating-point amounts are rejected.

1.2 Offer🔗ℹ

procedure

(offer id    
  product-id    
  kind    
  price    
  entitlement-policy-id) → offer?
  id : string?
  product-id : string?
  kind : (or/c 'one-time 'subscription)
  price : money?
  entitlement-policy-id : string?
Describes one stable thing a customer may buy. Identifiers are lowercase kebab-case. Provider product and price identifiers are mappings owned by the service and are not part of this value.
